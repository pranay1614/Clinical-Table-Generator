# Clinical Table Generator

## Overview
A Shiny application developed in R to generate clinical trial summary tables using synthetic clinical trial datasets.

## Features
- Demographics summary table (ADSL)
- Clinical trial data summaries
- Interactive Shiny application
- Reusable R functions
- Synthetic datasets for demonstration

## Technologies
- R
- Shiny
- bslib
- dplyr
- DT

## Project Structure
- `app.R` – Main Shiny application
- `R/` – Reusable R functions
- `data/` – Synthetic datasets

## How to Run
1. Install the required R packages.
2. Open the project in RStudio.
3. Run `app.R`.

## Disclaimer
This project uses synthetic data for demonstration and educational purposes only. No real patient data is included.
